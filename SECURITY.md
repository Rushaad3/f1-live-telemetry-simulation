# Security policy

## Reporting a vulnerability

Please do not publish exploit details or sensitive information in a public issue.

At present, this is a personal educational project and no dedicated security response team or private security contact has been established. If GitHub's private vulnerability reporting is enabled for this repository, use that feature. Otherwise, contact the repository owner privately through their GitHub profile before disclosing details publicly.

## Scope

The application does not open network listeners or receive external telemetry. It writes Excel files to a path selected by the user. Do not include private, identifying or confidential information in public issue reports.
